Floating Memo ポータブル版（Windows 11 x64）
==========================================

インストール不要です。.NET や Windows App SDK を別途入れる必要はありません。
メモ・音声・文字起こし・AI議事録は、この PC の中で処理・保存するよう作っています
（アプリのコードに通信機能はありません。ただし Markdown エディタの土台の WebView2 が
 Microsoft のサーバーへ接続することを確認しています。「既知の制約」参照）。

この ZIP には AI モデル（Whisper / Qwen3）は入っていません。
文字起こし・AI議事録を使う場合は、models フォルダの README_MODELS.txt の手順で、
公式の配布元から自分でダウンロードして置いてください。
モデルがなくても、メモの入力・自動保存・ノート管理・PDF / Word 書き出しは使えます。


■ 起動方法
1. FloatingMemo-Portable.zip を好きな場所にコピーし、右クリック →［すべて展開］で解凍します。
   （例: C:\Tools\FloatingMemo-Portable）
   ※ ZIP の中から直接実行せず、必ず解凍してください。
2. 解凍したフォルダの FloatingMemo.exe をダブルクリックします。
3. 初回、「Windows によって PC が保護されました」と表示された場合は
  ［詳細情報］→［実行］を選びます（署名のない個人作成アプリのため）。
   ネットからダウンロードした ZIP の場合は、解凍前に ZIP を右クリック →［プロパティ］→
  ［許可する］にチェックを入れておくと、この警告が出にくくなります。

フォルダ内のファイルは消したり移動したりしないでください。
フォルダごと別の場所へ移動するのは問題ありません。


■ 使い方
  Ctrl + Shift + M … どのアプリからでもメモを表示 / 非表示
  Esc              … メモを隠す（アプリは常駐したまま）
  Ctrl + R         … 録音開始 / 停止（停止後に自動で文字起こし → 録音したノートの末尾に「以下、AIによる文字起こし」として追加）
  Ctrl + N / W     … 新しいノート / タブを閉じる（ノートは削除されません）
  Ctrl + O         … 保存済みノートの一覧（名前・本文で検索、更新日時・名前で並べ替え）
  Ctrl + Shift + E … PDF / Word（.docx）に書き出し（ノート全文 または AI議事録のみ）
  Ctrl + Tab       … 次のタブ（Ctrl + Shift + Tab で前のタブ）
  F2               … ノート名の変更　　Ctrl + S … 今すぐ保存
  Enter / Tab      … リストの継続 / 字下げ（Markdown エディタ）
  F6               … エディタから下部のボタンへ移動
  右上の ×        … アプリを終了
  下部のマイク / スピーカーのボタンで、録音する音（マイク / PC 音声）を切り替えます。
  マイク横の ▾ で入力デバイス（Windows の既定 / 既定の通信デバイス / 特定のマイク）を選べます。
  「ステレオ ミキサー」はマイクではありません。声が録音されないときは、ここでマイクを選んでください。
  同じメニューの「マイク入力テスト」で、録音せずに声が届いているか確認できます（緑色に満ちれば OK）。
  録音中は、マイクのアイコンが緑、スピーカーのアイコンが青に、音の大きさに応じて満ちます。
  録音中に隠すと最小化され、タスクバーに「● 録音中」と表示されます。


■ AI議事録（試作）
  下部の議事録ボタン →「このノートからAI議事録を作成」で、文字起こしを議事録の下書きに整理します
  （Qwen3 4B は話題ごとの見出し、1.7B は 7 つの固定見出し）。録音・文字起こしが終わってから作成してください。
  文字起こしのないノートでは確認が表示されます（手で書いたメモだけから作る場合は「メモだけで作成」）。
  ・PC 内の小さな AI（Qwen3、llama.cpp）で処理します。クラウドには送りません。1 回に 1〜数分かかります。
  ・処理の流れ: ①専門用語辞書と文脈で聞き間違いを校正 → ②議事録を作成。進み具合は下部バーに表示されます。
  ・Qwen3 の GGUF ファイルを models\qwen に置くと使えます（README_MODELS.txt 参照）。
      Qwen3-1.7B-Q8_0.gguf   : 軽量。必要メモリ 約2.5GB。速いが内容の取り違えが多め
      Qwen3-4B-Q4_K_M.gguf   : 標準。必要メモリ 約3.5GB。原文に忠実
  ・使うモデルの切り替え、校正の有無、専門用語辞書（インポート・追加・編集・削除、登録候補の承認）は、
    議事録ボタン →「AIモデル・専門用語辞書の設定…」で行います。辞書は最初は空で、自動で置き換えることはありません。
  ・原文は変更されず、議事録は「（ノート名）（AI議事録）.md」として別に保存されます。
  ・議事録の見出しと書き方は、Markdown か JSON のテンプレートとして読み込み、議事録ボタン →「議事録の形式」で選べます。
  ・GPU（Vulkan 対応のドライバー）があれば、文字起こしと AI議事録に自動で使います。使えないときは CPU で動きます。
    「AIモデル・専門用語辞書の設定…」で「自動／GPU 優先／CPU のみ」を選べます（再起動後に反映）。
  ・AI は間違えることがあります。原文にない担当者・期限は「未確認」、根拠が確認できない項目には ⚠、
    校正で確信が持てない語には〔要確認〕が付きます。必ず原文と照らし合わせて確認・修正してください。


■ 保存先（使う PC のユーザーごと）
  メモ        : %USERPROFILE%\FloatingMemo\draft.md と notes\*.md（1 ノート = 1 ファイル）
                （例: C:\Users\<ユーザー名>\FloatingMemo\notes\会議メモ.md。UTF-8 の Markdown）
                以前のバージョンの draft.md はそのまま最初のタブとして開きます。
                OneDrive の同期対象（ドキュメント等）を避けた場所です。
  設定        : %LOCALAPPDATA%\FloatingMemo\settings.json（ウィンドウ位置・サイズ・録音の選択・マイクのデバイス ID）
  タブの状態  : %USERPROFILE%\FloatingMemo\.floatingmemo\（本文は含みません）
  エディタ    : %LOCALAPPDATA%\FloatingMemo\WebView2\（Markdown エディタのキャッシュ）
  診断ログ    : %TEMP%\FloatingMemo\transcription-diagnostics.log（数値のみ）
  録音の一時ファイル : %TEMP%\FloatingMemo\recordings\（文字起こし後すぐ削除）
  エラーログ  : %TEMP%\FloatingMemo\crash.log（異常終了時のみ。メモの内容は書きません）
  アプリのフォルダには何も書き込みません。読み取り専用の場所に置いても動作します。


■ 必要な Windows の権限・設定
  ・管理者権限は不要です。
  ・マイク録音には、Windows の［設定］→［プライバシーとセキュリティ］→［マイク］で
   「マイクへのアクセス」と「デスクトップ アプリがマイクにアクセスできるようにする」を
    オンにしてください。
  ・PC 音声の録音に特別な権限は不要です。
  ・Markdown エディタは Windows 11 に標準搭載の「Microsoft Edge WebView2 ランタイム」を使います。
    ランタイムがない環境では自動で簡易エディタ（プレビューなし）になります。


■ 既知の制約
  ・Windows 11（x64）専用です。ARM 版 Windows では動作確認していません。
  ・Ctrl + Shift + M を他のアプリが使っている場合はエラーが表示され、ホットキーなしで起動します。
  ・すでに起動している状態でもう一度起動すると、既存のメモが前面に出るだけです（二重起動しません）。
  ・アプリ起動中にノートを他のエディタで編集した場合、アプリ側に未編集なら自動で読み直します。
    両方で変更があったときは確認が表示され、もう一方は「(競合 日時).md」として残ります。
  ・PC 音声は「既定の再生デバイスの音全体」を録音します（特定アプリだけの録音は不可）。
  ・スピーカー使用時にマイクと PC 音声を同時録音すると、二重に録音されることがあります（ヘッドホン推奨）。
  ・文字起こしは録音停止後にまとめて行います。初回はモデル読み込みのため数秒かかります。
    長い録音ほど時間がかかります（CPU のみで処理）。
  ・文字起こしの精度は Whisper base モデル相当です（models\whisper\ggml-base.bin を置いた場合）。
  ・タスクトレイ常駐、設定画面、Windows 起動時の自動起動はありません。
  ・Markdown エディタの土台である WebView2（Microsoft Edge の部品）が、起動中に Microsoft のサーバーへ
    接続することを確認しています（Edge 自体の設定・更新などの通信と考えられますが、内容は未確認です）。
    エディタのページは外部と通信できない設定にしていますが、この接続自体は止められていません。
    完全なオフライン動作は保証していません。
  ・最後のタブを閉じると「開いているノートはありません」と表示されます（ノートは消えていません。Ctrl+O で開けます）。
